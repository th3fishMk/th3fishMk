# Projects

This is just a collection, a "documentation" for IDEAS that I *might* or might not work on, I keep a separate (but unpublish) similar list for personal but private (local) projects and I've decided to also keep a list for public and open source projects

The actual reason I created this list is because I have this problem on which I start a project, work a bit on it and then I leave for another and then come back to the first, a bit more on it, and then start another one, and then I get back to the second and so on and so forth

The possible status are:

- `planned` I have the idea, but haven't started yet
- `started` I have already started this project, but its not ready for production
- `testing` This project is already in use! But not mature enough
- `canceled` It was cancelled for whatever reason
- `published` It is good enough to be used by anyone
- `abandoned` Although it was published, I've decided this project was not worth maintaining
